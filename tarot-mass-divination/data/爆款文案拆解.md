# 大众占卜爆款文案拆解（2026-08-18 留档）

> 三篇抖音/B站爆款（图文长文 ×2 + 视频口播 ×1）的元素与结构拆解，及短图文（`interpret_short.md`）的借鉴落地。已升级的提示词条款以「→ 已落地」标注。

## 一、爆款万能骨架（三篇共用）

```
① 开头直给：答题 or 封神，第一句就抓住
② 状态翻译：把读者说不清的状态一语说破
③ 微场景对号入座：高颗粒生活细节，"说的就是我"
④ 因果机制：短板/延迟都有出处 → 诊断报告感
⑤ 重框定：一切负面 = 功课/保护/渊源，零冒犯
⑥ 轻出路：零成本、不可证伪（修心/慢一点/定力）
⑦ 金句收尾：可截图的比喻 or 条件化希望闭环
```

## 二、底盘四铁律（比结构更重要）

1. **零可证伪断言**——无时间、无具体事件，永不被打脸 → 已落地（时间模糊词 + 禁具体事件预言）
2. **负面全重框定**——短板是使命的副作用，延迟是宇宙的保护 → 提示词原有
3. **出路永远轻**——绝不给分手/辞职级行动，只给心态功课 → 已落地（禁重大人生行动建议）
4. **专属感错觉**——人人都套得进，但每个人都觉得只说给自己（②③④ 叠加的结果，非条款）

## 三、三条路线对比

| | 文案 1（封神） | 文案 2（疗愈） | 文案 3（圈层点名） |
|---|---|---|---|
| 媒介 | 图文长文 | 图文长文 | 视频口播 |

| 短板处理 | 高贵出处（理想受阻→偏激） | 未愈旧伤（延迟=宇宙保护） | 无缘不聚（缘浅=渊源） |

## 四、爆款元素总表（按威力排序）

| 元素 | 机制 |
|---|---|
| 状态翻译 | 替读者说出说不出口的话 → 被理解感 |
| 负面重框定 | 批评包装成理解，防御归零 |
| 微场景对号入座 | 嘴上过去了/心里抽一下式反差，高颗粒 |
| 因果机制链 | 情绪→断链接→失灵式诊断感 |
| 金句比喻 | 排队靠近式拟物化，截图传播钩 |
| 条件化希望闭环 | 没来=没修好，来了=修好了，正反手赢 |
| 身份加冕 | 优越感社交货币（调性不符，我们不借宏大版） |
| 身份点名清单 | 收窄换狂喜（改造后借：锚"会问这个问题的人"） |
| 双语义两头堵 | 没来/没认出，永不被打脸 |

## 五、短图文借鉴清单（6 条，全部已落地 `interpret_short.md`）

| # | 借鉴点 | 落位 | 说明 |

| 2 | 按问题锚定人群点名 | 对号入座段开头 | 只锚"会问这个问题的人"（点开=自我筛选完成），一两句精准画像，不罗列清单；与文案 3 差异：锚状态身份不锚职业圈层 |
