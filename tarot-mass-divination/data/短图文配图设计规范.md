# 大众占卜短图文 · 配图设计规范（现行定稿）

> 参考来源：即梦识图拆解爆款参考图（「你未来的结婚对象类型」短图文）+ 多轮用户反馈逐条打磨定稿。
> 适用：大众占卜**短图文**（封面 3:4 + 每选项一张 3:4 解读图），区别于**长图文**（封面 + 逐牌模块超长图）。
> 实现脚本：`render_short_divination.py`（Playwright HTML/CSS 纯排版，文字不靠 AI 生图）。

## 一、配色体系（统一，不花哨）

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#E8D4B4` | 深暖褐羊皮纸底（**古朴**），**所有选项统一**，无装饰、无分割线 |
| 分组标题 / 组号 / 关键词 | `#C4677E` | 深玫瑰红（深羊皮纸底上更清楚），加粗 |
| 正文 | `#3B3328` | 低饱和暖炭黑 |
| 辅助（问题/牌面名） | 正文色 / `#A79B88` | 问题同正文色；牌面名更小更淡 |

## 二、结构（自上而下）

1. **顶部**：组号（第X组，13px 粉粗）+ 占卜问题（正文色，semi 常规字重，**不显示牌阵名**）
2. **牌面小图行**：每张牌一张小图（24×42，逆位旋转 180°），图下牌名（小、淡）
3. **关键词组**（同组紧凑）：
   - `关键词：` 标题 + 关键词**同一行、同字号同样式**（粉粗），4-6 个词（最多 8），长短混用可含单字
   - **换行**输出一句美好祝福（正常色），如"你们的关系会走向一段被祝福和爱意包裹的见证，家的温情。"
4. **星座与四元素**（下一组）：标题粉粗独占一行，正文换行在其下；按元素翻译（权杖=火、圣杯=水、宝剑=风、星币=土；大阿卡纳按星座/行星）
5. **状态翻译散文**：命名用户说不清的状态 → 对号入座微场景 → 重框定 → 结尾落地金句

## 三、字号（全篇只有 2 种）

- **标题档**：组号 / 关键词（含关键词文字） / 星座与四元素，**固定 13px** 加粗粉色，三组一致不随内容变
- **正文档**：问题 / 牌面名 / 两组正文 / 散文，统一 `1em` = **10.5px**（全局统一字号，三组一致）
- 缩字：`.s-scale` 缩放容器按 0.5px 步长缩 base 字号，下限 **9.0px**（IIFE 立即执行，防末行被裁）

## 四、间距与排版

- **块间距拉开**：关键词组 → 星座与四元素 → 散文正文，各 **14px**；关键词组内部（标题+关键词+祝福）紧凑成一组
- 牌面小图行、段距、内边距（16/10）紧凑，为容纳 460-540 字正文腾空间
- 羊皮纸哑光质感 + **古朴程序化羊皮纸纹理**（即梦识图"打印在暖米棉麻信纸上"的质感；`_make_parchment_uri` 生成：**深暖褐底** + ~1.5× 块状细颗粒（介于逐像素与2×2之间） + **低频正弦斑驳**（暗处偏棕、亮处偏暖的包浆，天然无缝）+ **随机纤维细线/细点**（偶有几根）+ **老化渍斑**）+ **`::before` 边缘泛黄老化晕染**（旧纸中间亮、四边泛黄），无边框无分割线、信息松弛留白、低对比长时间阅读不疲劳

## 五、内容格式（interpret_short.md）

- **关键词**：4-6 个词（最多 8），顿号分隔，长短混用可含单字，重在意象，不要全是四字词；**关键词行后换行写一句祝福**
- **星座与四元素**：按元素→人设翻译，说人话、具体，不解释牌意，牌名自然融入
- **状态翻译散文**：三个呼吸节奏（状态翻译式直球结论 → 对号入座画面 + 重框定 → 结尾落地）
- 总字数 460-540 字（统一 10.5px 字号能放下）；**每张抽到的牌都必须点到**；无「」、无破折号；不用 `---` 分块；**无硬 CTA 按钮**（抖音版允许品牌露出，见七）

## 七、抖音品牌露出规范（2026-08-20 加）

抖音短图文**允许品牌露出**（区别于小红书/其他平台默认不带）：

1. **封面 = 即梦 image skill 生成**（AI 封面，参考图复刻版式，见 jimeng-image skill）。**2026-08-20 起旧程序化封面（render_mass_divination cover_html）已废弃**，本脚本不再渲染/清理封面。封面上的品牌按需走即梦生图 prompt 的参考图/文案。
2. **选项页品牌钩子**（三套主题统一，`.s-foot`/`.m-foot`，**固定不随正文缩字**）：`[logo] Luna 在[塔罗气泡App]等你来聊聊` —— App 名用主题 accent 色加粗高亮（parchment/black 粉色、memo 备忘录橙），比弱水印强、做软引流。项目铁律：App 大写、IP 无冒号无空格、首次出现用完整表达。

> 不做独立品牌尾页/硬 CTA 按钮（不伤爆款内容传播力，品牌钩子即软引流）。文案遵循项目 CLAUDE.md 品牌铁律。
