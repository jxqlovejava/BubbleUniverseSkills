# 即梦生图提示词 · 大师心法 + 大众占卜封面风格预设库

> **本库与 `prompt-examples.md` 配套，写提示词前两个文件都要翻**：本库 = 怎么写（心法+模板+预设库+硬约束），examples = 好样例长什么样（示例 + 六块通用件 + 共性规律）。真人像/氛围图按拼装顺序写：**场景定调词（开头）→ 主角配方块 → 姿态 → 服装/织物 → 光的三件套 → 肤质/发丝细节 → 风格帧 → 负向块**；同款场景先在 examples 抄骨架。
> 适用：Agent 模式（agent_generate.py）+ 图片 5.0 Lite，3:4 竖版封面图。
> Lite 比 Pro 指令遵循略弱，所以本库的模板都遵循：**单主体减法 + 空间关系显式化 + 硬约束集中后置**。

---

## 一、大师心法（七条，决定上限）

1. **写照片，不写想法。** 动笔前心里先有一张具体照片（谁、在哪、什么光、镜头多近），把"看见的"写出来，不写"想表达的"。`一个疲惫的女人深夜想起往事` 是想法；`深夜卧室，女子侧坐在床沿低头看手机，屏幕暖光照亮半张脸，房间里只有床头一盏小夜灯` 是照片。模型只认识后者。

2. **七层结构，顺序即权重。** 即梦 Agent 对中文长句理解很好，按下面顺序写，注意力自然分配对：
   ```
   ① 主体（谁/什么，含外观描述）
   ② 姿态动作（身体朝向 + 视线方向）
   ③ 道具交互（道具朝向 + 接触状态）
   ④ 环境（地点 + 时间 + 天气/氛围）
   ⑤ 构图（景别 + 机位 + 主体位置占比）
   ⑥ 光线（方向 + 质感 + 色温）
   ⑦ 风格质感（媒介 + 相机/镜头 + 调色）
   ```

3. **空间关系必须写成"画面可见的结果"。** 这是常识翻车（照片朝向反了、牌面朝下等）的根因：模型对"看不见的一面"没有推理能力。`人拿着照片看` 需要模型推理"照片正面对着人眼"——看不见，必翻车。直接写结果：`照片正面对着镜头，人像清晰可见`。**凡是朝向/正反/里外/上下关系，全部翻译成镜头里能看到的样子。**

4. **位置三件套：九宫格 + 占比 + 朝向。** "人物位置不太对"的根治法：
   ```
   人物位于画面左三分之一竖线附近（不居中），
   人物高度约占画面高度的三分之二，头部低于画面上沿，
   身体朝向右侧，视线望向右下方的月亮，留出左上方空间
   ```
   只写"人物在左边"不够，必须三件套齐全，缺一件就漂移。

5. **一句话一个信息，禁止嵌套和指代。** `身穿米色针织开衫的年轻女子` ✅；`穿着她那件心爱衣服的女人` ❌（"心爱"不可见、"那件"是指代）。所有形容词都必须是"镜头能拍到的"。

6. **硬约束集中后置 + 必须/严格保持标记。** Agent 模式 prompt 会被即梦 Agent 再加工，前面的内容可能被"创作性发挥"，放最后集中声明的"必须"约束存活率最高：
   ```
   ……（自由创作部分）……
   必须严格保持：3:4竖版构图；人物位于画面下部三分之一；画面上部大面积纯净留白；
   塔罗牌正面朝上；禁止任何文字、水印、边框。
   ```

7. **减法优于加法。** 每加一个元素，其他所有元素的准确率都下降（尤其 Lite）。每格/每张只给 **1 个主体 + ≤2 个陪衬物**。`一条桃花枝` ✅，`樱花树下浪漫邂逅的男女剪影` ❌（实测：元素一多就脏、就 AI 味）。

**跨示例元知识（从 `prompt-examples.md` 抽象，8 条，适用一切生图，不限于人像）**：

1. **约束靠"专名/符号"，不靠抽象堆词。** 胶片模拟点名（`Fujifilm Classic Negative / Portra 400 / Cinestill 800T`）一个专名词锁死一套风格，胜过堆十个质感词；相机参数点名（`85mm f/1.8 ISO 400`）；年代感 = 时代符号清单（服装/妆容/道具/调色逐项点名），不抽象写"复古"。
2. **情绪/氛围用"可见证据"，不用情绪词。** `眼周微红、睫毛微湿、眼中略带血丝` > "忧伤的表情"；`冷红脸颊（cold flush）` 把"冷"写到皮肤上；环境不只背景，要"写到人身上"（雪花落发/风里碎发）。
3. **光必须三件套 + 反向约束。** 光源 + 照在哪 + 什么效果（`机顶闪光 + 脸颊 + 眼神光`）；调色反向约束防溢出（`不黄、不过滤镜`）；叙事性布光（diegetic）= 光源来自画面内物体，背景自动隐黑。
4. **负向块是兜底，且要"主动可信小瑕疵"。** 无塑料感/无变形手/无AI标签 是防御；`保留自然瑕疵和轻微不完美，不做过度润色` 是进攻——过度完美=塑料感。
5. **结构 = 给模型的分层注意力。** 场景定调词放开头（`warm vintage ryokan aesthetic`）；复杂图用分段编号（主体/构图/光/色彩/背景/后期/负向），比一条长句稳。
6. **姿态不对称破摆拍感。** `一条腿弯曲另一条放松 + 身体微倾 + 肩膀不对称 + 头倾斜`——对称=摆拍，不对称=抓拍；非直视镜头（侧看/低头/微转）同理。
7. **风格帧二选一不混搭。** 胶片写实 / 日系负片 / 直射闪光 / 湿版做旧 / Y2K 数码是独立帧，混用必串味；选对口味（Velvia=高饱和鲜艳 vs Classic Negative=低对比怀旧）。
8. **人物一致性 = 配方块逐字复用。** 主角外貌配方块跨图逐字复制，只改发型/服装/场景；要求更高上 `--ref`。

## 二、常识纠错对照表（翻车模式 → 修正句式）

| 翻车模式 | 根因 | 修正句式（直接抄） |
|---|---|---|
| 照片/牌面朝向反 | 模型推理"看不见的一面" | `照片正面对着镜头，照片里的人像清晰可见` / `塔罗牌正面朝上摊开在桌面，牌面正对观众`。**更稳：改构图，让朝向无关紧要**（牌摊桌上俯拍、人背影） |
| 模型乱加手持图像道具（照片/卡片/手机） | 模型爱自由发挥，且自带图像道具必然翻面 | 不需要就显式禁：`手中不要出现照片、卡片、手机等自带图像的物品，手中只有{明确物品}`；需要就锁朝向（上行）。**手持图像类道具永远避开**（改道具静置/手部出画/背影） |
| 人物位置漂移 | 只写了"人物在左边" | 位置三件套（心法4）逐项写全 |
| 手部畸形/六指 | 正面手持是高风险构图 | ① 换构图规避：背影、俯拍、道具静置、手部出画；② 必须出手时写：`双手自然捧住杯子，手指完整清晰，指节自然弯曲，手部细节准确`，并避免特写景别 |
| 道具悬浮/穿模 | 重力与遮挡关系弱 | `物体平稳放置在木桌面上，接触处有真实柔和的投影` |
| 文字乱入 | 模型爱加装饰字 | 硬约束块里：`画面中禁止出现任何文字、字母、数字、水印、Logo` |
| 镜像/乱码文字 | 生图模型画字天生不可靠 | 别让 AI 画正文文字，用 HTML/CSS 模板叠字（项目现行方案）；AI 只画无字背景 |
| 多出人物 | "氛围感"暗示了人 | 明确写 `画面中只有一个人` / `无人物` |
| 蓝紫冷调乱入 | 默认审美偏冷 | `整体深暖棕色调，禁止蓝色、紫色冷色调`（品牌铁律） |
| 风格串味 | 风格词混用 | 一张图只用一个风格预设，禁止跨预设拼词 |

## 三、通用模板骨架

```
【主体】+【占比/位置（三件套）】
【姿态：身体朝向 + 动作 + 视线方向】
【道具：名称 + 朝向 + 放置/接触状态】
【环境：地点 + 时间 + 氛围】
【景别/机位：特写|中景|全景 / 平视|俯拍|低角度】
【光线：方向 + 柔硬 + 色温】
【风格质感块（从下面预设库选一个整块抄）】
【硬约束块：必须严格保持……】
```

封面图通用硬约束块（每张必带，可按需删改）：

```
必须严格保持：3:4 竖版构图；画面中上部（或下部）保留大面积纯净低纹理留白区域供排版使用；
主体不遮挡留白区；画面中禁止出现任何文字、字母、数字、标点、水印、Logo、边框；
整体深暖棕色调，禁止蓝色紫色冷色调。
```

**大众占卜封面出图模板（2026-08-20 实测跑通，宫格自适应）**：

参考图 + 复刻样式时，版式/风格交给参考图，prompt 只锁三件事：**宫格版式、选项文字、张数**。别列每格内容（会触发版式漂移 / AI 味）。

```
这是大众占卜封面图，{风格短词，如：漫画人物局部风格}，每个宫格一张画面，每格一个选项。
请你完全复刻参考图的版式和{风格}，生成{N}张全新的封面图，图片不要雷同。
必须严格保持参考图的宫格版式不变（不要变多不要变少），每张换新画面和选项文字。
画面干净，除每格选项文字外禁止出现多余文字、水印、Logo、边框。
```

- **宫格数由参考图决定，模板自适应，不用写死 N**。已实测三种版式：影视人物=3宫格（选项壹贰叁，右上壹/左中贰/右下叁）、梦幻人物=3行竖排（Group 1/2/3 靠左）、漫画人物局部=2×2四宫格（A/B/C/D）。参考图是几宫格就复刻几宫格。
- **`--count {N}` 一次出 N 张**（Agent 模式 prompt 控张数版式稳定；别逐张 `--count 1`——太慢）。
- 选项文字由参考图复刻（壹贰叁 / A/B/C / Group 1-3），prompt 写「每格一个选项」即可，不强行指定字符。
- 验证宫格数：macOS Vision OCR 看选项坐标——N 个选项分布 = N 宫格（投影法会被弱分隔线误导，判错）。

## 四、风格预设库（每类一块，整块复制后填空）

### 预设A · 影视人物（真人质感）

**定位**：真人实拍感、电影氛围，用于"人物故事感"封面。融合既有人像三原则（自然皮肤 / 自然柔光 / 人物一致性）。

```
{年龄性别}，{一句话外貌：发型+肤色+气质}，{一句话服装：材质+颜色}，
{位置三件套}，{身体朝向+动作+视线方向}，
{道具及朝向}，{地点+时间}，
{景别，如：中景平视}，
{光线：方向+柔硬+色温}，
影视质感实拍风格：人物保留自然毛孔、细微汗毛、肤色变化和肌理细节，
未经美颜修饰，真实皮肤反光，光线下呈现自然明暗层次，轻微瑕疵感；
自然环境柔光，柔和散射光照亮人脸面部，形成细腻的明暗过渡，
保留真实皮肤纹理和自然肤色，光线柔和通透，真实生活感；
浅景深背景虚化，35mm 胶片色调，{色调：深暖棕/低饱和}，电影感构图。
必须严格保持：画面中只有这一个人；人物一致性（同一人特征不变）；
{封面通用硬约束块}
```

**避坑**：
- 人物跨图一致：同一组图用**完全相同的外貌描述块**逐字复制（发型/服装/配饰一字不改），只换动作场景；要求更高上 `--ref` 参考图。
- 手持道具是最高危场景（照片朝向、手指数量双重风险）。优先级：背影/侧影 > 道具静置 > 手持。非要手持，道具朝向和手部描述都要写全（对照表第1、3行）。
- **规避乱加道具 = 锁道具，不锁姿势**：保持自然生活动作（持物/张望），加 `手中只有{明确物品}，不要出现照片、卡片、手机等自带图像的物品；人物腿上/身上不要出现多余杂物`。**别为了规避道具把姿势改成端正交叠手/端坐**（摆拍感=AI感，用户实测 v3捧热饮 > v4交叠手）。图像类道具（照片/卡片）手持**永远避开**。
- 情绪别用词堆，用可见证据："疲惫"→`眼下有淡淡阴影，肩膀微微下垂`。
- **AI感 = 过度完美（绝对禁止）**：真人像提示词禁用「无瑕/完美/精致/清透/柔和/对称/光滑/瓷白/水润」等美颜词——直接喂 AI 感；叠加 examples **块7反AI纪实块**（表情/眼神/姿态/构图/光线/背景每维度留一点"不完美"），并用块6 负向加 `AI感/CG感/网红脸/完美对称五官`。

### 预设B · 静物油画

**定位**：古典油画静物，物有神性，适合牌阵、蜡烛、信物类封面。

```
{主体1}，{主体2，最多再两样陪衬：如一支蜡烛、一叠旧信}，
主体位于画面下部中央，{道具朝向：如塔罗牌正面朝上摊开}，
平稳放置在{桌面材质：深色旧木桌/大理石}上，接触处有柔和的真实投影，
{环境：如深夜书房，背景深暗虚化}，
中近景平视略俯，三角形经典静物构图，
{光线：左侧窗光/烛光，单侧柔光，明暗过渡细腻}，
古典油画风格：荷兰黄金时代静物画气质，厚涂笔触清晰可见，
画布纹理质感，颜料层次丰富，深色背景与主体高光对比（伦勃朗式明暗），
{色调：深暖棕/暖金}，哑光油画光泽。
必须严格保持：每样物体形态完整准确，不变形不穿模；{封面通用硬约束块}
```

**避坑**：
- 陪衬物 ≤3 样，多一样就挤。
- "厚涂笔触清晰可见、画布纹理"必须写，不写会被画成数码插画风（丢油画味）。
- 油画风格出镜率最高的翻车是**物体边缘过度发光**——硬约束加一句`物体边缘无发光描边`。

### 预设C · 风景 / 场景（无人物）

**定位**：氛围场景封面，靠环境讲故事。

```
{场景主体：如一轮金色圆月}，位于画面上三分之一中央，
{前景：如近景暖色木桌摊开三张塔罗牌，牌面朝上}，
{远景：如深夜城市天际线，虚化}，
{时间+天气：深夜，薄雾}，
全景/远景，平视，
{光线：月光柔和洒落，色温暖金}，
{风格块二选一}：
  写实摄影风：风光摄影质感，层次分明（前景/中景/远景纵深感），
    自然色彩过渡，{色调}，空气透视感，高清细节；
  治愈插画风：治愈系扁平插画，柔和干净的线条，大片留白，{色调}，静谧氛围。
必须严格保持：无人物；{封面通用硬约束块}
```

**避坑**：
- **前中远三层各写一句**，不写层次就会糊成一片贴图感。
- 光线要具体到"哪来的光、照在哪"（月光洒在桌面上），只写"氛围温暖"没有用。
- 塔罗牌永远显式写 `牌面朝上`。

### 预设D · 情绪特写（局部/手/静物，无人脸）

**定位**：最高成功率预设——规避人脸/手部风险，靠局部讲故事，深夜情绪款封面首选。

```
{局部主体：如一只手/一杯冒热气的茶/亮着暖光的手机}，
位于画面中央偏下，{朝向与状态：如屏幕正对观众，显示柔和暖光}，
{接触状态：平稳放置/手指完整清晰}，
{环境：深夜卧室桌面，背景大面积虚化}，
特写，微俯拍，
{光线：单侧暖光，柔和明暗过渡}，
浅景深大虚化，85mm 镜头质感，{色调：深暖棕}，胶片颗粒感，安静氛围。
必须严格保持：画面中不出现人脸；手部（如出现）五指完整清晰；{封面通用硬约束块}
```

**避坑**：
- 手机/镜子/水面这类"反光面"别指望反射内容正确——写 `屏幕显示柔和暖光（内容虚化不可辨）`，别写"屏幕显示聊天记录"。
- 手出现在特写里就降级成"局部入画"：`画面下缘露出手持杯沿的指尖`，比整只手安全。

### 预设E · 治愈系扁平插画（现行管线风格）

**定位**：深夜电台杂志风无字背景（note 系列组图），项目已实测跑通，保持现有后缀不动：

```
治愈系扁平插画风格，竖版3:4构图，深夜暖棕主色调（奶棕/暖金月光），
柔光氛围，温馨疗愈感。画面中禁止出现任何文字、字母、数字、标点符号、Logo、图标。
禁止蓝色紫色冷色调。中上部与下部留出大面积的纯净、低纹理留白区域供排版文字卡片使用。
```

### 预设F · 日系写真风人像（自然光·户外）

**定位**：日系杂志写真实拍风，人物 + 自然场景，治愈/沉静氛围。从日系九段式提示词（主題/主体/表情/服装/背景/构图/质感/负向）提炼，招牌技巧三个：**镜头参数化 + 环境反光 + 前景对角线运动模糊**。适合"人物在花田/草地/窗边"的治愈系封面。

```
{年龄性别}，{一句话外貌：发型+发色+气质}，{一句话服装：材质+颜色}，
{位置三件套：人物位于画面下部至中央，脸在中央偏右，头低于画面上沿，
 身体{朝向}，{视线：闭眼/看向镜头}}，
{姿态与遮挡：仰卧/坐/立 + 肢体与环境的接触遮挡，部分肢体可自然出画}，
{环境：季节+植物花田/草地 + 时间+天气}，
中近景，85mm 等效，焦点对在脸上，背景花草浅景深略虚化，
前景{元素}呈对角线方向运动模糊，从{方位}向{方位}流动，
{光线：高位自然太阳光，偏硬偏暖，{方向}受光，脸颊/发丝/锁骨有明亮高光，
 花叶在皮肤上落下细长投影，地面/草地的{补光色}反光从下侧回映到脸和下颌}，
日系写真质感：真实胶片颗粒感，杂志人像的沉静色调，
皮肤保留血色、毛孔和细微肌理，不过度磨皮、不塑料感；
发丝根根分明有束感，几缕被风拂动；衣物有真实面料纹理和褶皱。
必须严格保持：画面中只有这一个人；五官表情自然；
{封面通用硬约束块}
```

**避坑**：
- **光必须写"照在哪、落什么影、哪来回光"三段**，只写"从哪来"会平、会塑料感。`草地的绿色反光从下侧回映到脸和下颌` 是让光真实的高性价比一句。
- 前景运动模糊是低成本的风感 + 构图骨架：`前景花穗呈对角线运动模糊，从左上向右下流动`，一次交代风、景深、画面走向。
- 表情写可见证据：`眉放松、唇轻闭`，别写"安详/治愈"。
- **写真人像通用负向块（可直接抄）**：`不自然的表情和视线，多余或缺失的手指，肢体融合、关节错位，服装与身体接触不贴合，物体悬浮、重力异常，透视错误，影子与光源方向矛盾，过度美颜磨皮，塑料感皮肤，乱码文字、Logo、水印`。
- 与预设A的分工：A 偏电影叙事暗调，F 偏日系自然光通透、强调反光与发丝细节。**一张图只用一个预设，禁止跨预设拼词**。

### 预设G · 自然感美女/情侣实拍（夏日逆光·第一人称情侣视角）

**定位**：电影感实拍人像，超写实，主打**逆光勾勒发丝 + 写实肤质 + 第一人称情侣 POV 手入画**。用于"自然感美女/情侣照片 + 产品界面卡片"的抖音图文背景——人像自然、无塑料感，主体偏一侧给叠字叠卡留呼吸空间。招牌技巧三个：**镜头参数化（50/85mm）+ 逆光发丝主角 + 第二人只露局部手**。

```
Cinematic portrait photography, ultra-photorealistic, vertical composition at 3:4 aspect ratio,
50mm or 85mm portrait lens rendering, shallow depth of field, clean translucent
summer natural-light color grading — not overly yellow, not over-filtered.
Subject: a young beautiful adult East Asian {woman|woman couple}, {一句话脸型+五官，
 如 soft heart-shaped face, refined classical features, bright almond/fox eyes, petite
  nose bridge, naturally full lips}，{整体气质：sweet, sunny, energetic, cute with a touch of allure}。
Gaze highly engaging — bright, clear, natural catchlights, as if it speaks;
corners of mouth slightly lifted, expression gentle, vivid, natural.
She {walk|stands} along a {场景：garden stone path / tree-lined lane / European street / courtyard},
{right hand reaching back to hold the hand of someone behind her; only their hand appears in
 the {position三件套：lower-left corner} — like a first-person couple's POV snapshot; 单人时无此句}。
She glances back at the camera while her body stays in a forward walking motion, posture
elegant and natural, clearly a candid captured moment with a faint in-love feeling.
Long {发色 hair color} hair, {style：naturally wavy / relaxed big waves / airy bangs / half-up},
many strands tousled and flying in the wind, richly layered and dynamic.
Strong natural side-backlight rims the hair edges — clean, crisp rim light and
semi-translucent glow, hair edges lit as if by sunlight, light and luminous.
This is the core highlight of the image.
She wears {服装：white lace slip dress / beige slip dress / light-blue short-sleeve top with
 white skirt / light-pink fitted dress}, fabric texture natural, material light and soft.
Bright natural summer sunlight realistically warms her skin, shoulders, collarbone, and
clothing with soft, clean highlight transitions.
Skin texture: extremely realistic — visible fine pores, natural skin texture, faint
imperfections, subtle tone variation, soft sheen. Cheeks, nose tip, shoulders show natural
delicate gradations in sunlight. Translucent, healthy, real and refined — no plastic look,
no waxwork, no over-smoothing.
Background: soft atmospheric blur, never distracting.
必须严格保持：{主体偏{主体位置}侧，{对侧}上部保留大片留白（供叠字/叠卡）}；
人像自然不摆拍；画面中禁止出现任何干扰文字、Logo、水印。
（封面通用硬约束块按需叠——若照片叠产品卡则**去掉**"必须严格禁止文字"里与卡片冲突的限定，
 本模板照片区域本身无字，卡片文字由 HTML/CSS 叠加，两者不冲突。）
```

**避坑**：
- **比例句与输出口径必须一致**：用户原稿比例是 `2160x3840`(9:16)，但本模板照片按 3:4 输出，故上方模板已改为 `vertical composition at 3:4 aspect ratio`。若做 9:16 场景（如微信背景），把比例句换回 `2160x3840 vertical composition`——**prompt 与 `--ratio` 不一致会让模型先预期高构图再被强裁，导致主体偏移/面部裁切**。
- **发丝逆光 = 本预设的核心高光**，必须写全 `<side-backlight rims the hair edges> + <rim light> + <semi-translucent glow>` 三段，只写"逆光"会平、发丝糊成一团。
- **肤质负向块（可直接抄）**：`Avoid: over-smoothing, plastic skin, CG look, anime look, wig look, stiff expression, dead eyes, stiff poses, overall yellow cast, overexposed face, distorted features, wrong fingers, deformed hands, cluttered background, heavy influencer retouching`。
- **第二人只露局部手**：情侣视角时，对方手只出现在角落（`lower-left corner`），**绝不全身/双手十指相扣**——手部翻车是重灾区（参考 prompt-examples 共性规律 3 手部风险四级规避）。
- **为主体留白**：图片 prompt 里明确要求"主体偏一侧 + 对侧大片留白"，否则叠卡会盖脸。对照参考图（人像右侧 + 卡片左侧）。
- 与预设F的分工：F 是日系通透静态人像（花田/草地/窗边，无人入画），G 是电影感**动态实拍 + 情侣 POV + 强逆光发丝**。**一张图只用一个预设，禁止跨预设拼词**。

## 五、生成后复检清单（30 秒/张）

- [ ] 朝向：所有牌面/照片/手机屏幕朝向符合预期（常识纠错表第 1 行）
- [ ] 位置：主体在预期九宫格区域，占比合理，没漂移
- [ ] 留白：叠字区无复杂纹理/主体入侵（粗查留白占比 ≥25%）
- [ ] 手部（如有）：指头数量、姿态自然
- [ ] 无文字乱入（macOS Vision OCR 扫一遍，顺带查镜像字）
- [ ] 色调：暖棕系，无蓝紫
- [ ] 一致性（组图）：人物/道具跨页一致

翻车处理原则：**能改 prompt 就别赌第二次随机**——把翻车点翻译成对照表里的修正句式加进硬约束块再重生，而不是原样重抽。
