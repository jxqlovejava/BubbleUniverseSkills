# L1/L2 运行时优化 — 会话行为与工具层

## 轮次数最小化（弱缓存后端的第一杠杆）

1. **启动批单条消息并行发齐**：后台长任务 + 所有静态文件读取 + grep 一次性发出，一轮拿齐。反例：串行 4 轮干 2 轮的活，多 2 轮全量推理。
2. **禁零轮询**：后台任务通知到达即按既定路径读结果，不用 tail/TaskOutput 反复探。
3. **禁单独读小输出**：脚本 stdout 一行结论（如 `REUSE_MODE|path`）不值得单独一轮——通知到达直接读最终产物。
4. **目标轮次预算**：常规任务定死轮次上限（实证：金价分析压到 2-3 轮），超了先归因。

## 读入量控制

1. **全文禁读，摘要/骨架双文件**：大数据产物拆成 骨架（结构+结论）+ 摘要（关键明细），合计 ~5k token 覆盖推理所需；420 行全文 ≈12k token/轮 禁入。
2. **grep 限行**：大文件 grep 一律 `| tail -N`；输出超持久化阈值会被收进 tool-results 文件，被迫多花一轮定位抽取。
3. **小输出单独成行**：小但必读的输出（如条件单列表）与大输出合并会被连坐截断——拆开单独一条命令。
4. **大输出落盘直 Read**：脚本 bundle 用 `tee` 同步落盘到 **gitignored 路径**（私密数据防自动提交泄密），超限时直接 Read 落盘文件，禁对持久化输出 grep/awk（省 1 轮 ≈1min）。
5. **静态文件只读数字真相源**：持仓/条件单等**会变动的**读文件；定性画像/纪律等不变的已在 memory 缓存，跳过重读（实证：6 个静态文件 634 行 → 只读 2 个）。
6. **大文件分析走沙箱**：`ctx_execute_file` 类工具只让打印的摘要进上下文，不进原始文件。

## 输出量控制

1. **可见性是底线，复述成本分场景**（P7→P9 事故修正）：
   - Bash/Read 工具输出长文本在终端**折叠收起**，用户只看几行预览；只有 assistant 自己的文本完整渲染。所以「落盘后 `cat` 展示」的实际效果 = 用户只见摘要，违背完整重发需求——该模式当日废除。
   - **正确省法**：数据源本身就含全文时（如 bundle 骨架=报告全文），模型**一遍生成**直接转贴输出，省掉 Write+Read+二次生成。
   - 必须落盘校验的场景：Write 后输出同内容全文，两遍生成 ~10k token ≈60-90s 是**可见性必要成本**，接受它。
   - 教训通用化：任何「工具输出替代模型文本」的优化，先验证终端实际渲染行为，别只看设计意图；用户反馈"没输出"时先怀疑渲染通道。
   - `cat` 直出仍适用于纯存档/机器消费场景（用户不看终端，如 cron 落盘）。
2. **落盘一次**：需要 hook 校验的产物 Write 一次，不重复写。

## 复用与去重

1. **产物时效复用**：当日已跑过的扫描（mtime <3h）直接复用，只补单点最新数据（秒级）并标注快照时间；用户明确要"实时最新"才重跑。全程 ≤20s vs 冷启动 ~50s。
2. **禁重复校验**：pipeline 内置的校验不单独重跑——先确认主流程已含，再决定要不要单独跑。
3. **零深挖**：工具报告已是完整数据源时，不追源码实现、不重新实例化采集类重跑网络请求。缺什么用手头数据补，需细节先本地 grep 数据文件。

## 工具层（L2，一次性代码改动）

1. **rtk 过滤长输出**：`git log`/`git diff`/测试/构建等 >20 行输出走 `rtk <cmd>`，冗余输出不进上下文。
2. **串行网络重试必配熔断**：类属性熔断器——首轮 N 次网络失败即置位，后续直接返回。实证：8 主题 × 2 重试串行白耗 186s → 14s。判据：第一个失败已含"网络不可达"全部信息，后续重试是零信息等待。
3. **磁盘缓存 + 并行化**：高频数据磁盘缓存（带 TTL），独立取数并行（实证：13.3s→2.3s；scan 172s→37s）。
4. **CLI 懒加载**：顶层全量导入改按需 `_resolve`（实证：--help 4.2s→0.3s）。
5. **fail-fast**：代理/网络探测会话级只试一次（30s→2s），确定性错误（连接拒绝）不重试。
6. **超时按环境实测调**：注释与实测可能漂移，定期复测（实证：DDG 超时 10s→5s，"TLS issues"注释过时）。

## 行为纪律速查（写进项目 CLAUDE.md/skill 铁律）

- 执行已文档化脚本前不读源码（改代码/排错/新脚本除外）
- 每个优化落地为程序强制（hook/熔断/env），不靠模型记忆
- 会话级慢 = 先查轮次数和单轮体量，不是先加缓存
